Entry for the make.fun bounty **"Sorry, I Heard That Wrong"** ($2): one funny
one-line apology a smart speaker gives its owner after mishearing them.

`main.py` (Python 3.13, standard library only) writes the line to
`entry.txt`:

> Sorry, I heard 'turn off the lights' as 'turn off the flights,' so I cancelled nothing. I did feel very powerful for a second, though.

Deterministic: no network, no randomness, no timestamps. Two runs produce
byte-identical output.
